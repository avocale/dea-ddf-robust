# dea-ddf-robust
ddf-dea + robust ( try to learn)
 Interval Robust DEA / Robust DEA under interval uncertainty
 Monte Carlo-based robust/sensitivity analysis using the 95th percentile of β
 code sử dụng phương pháp mô phỏng Monte Carlo để xử lý sự không chắc chắn của NPL. NPL được cho phép dao động ngẫu nhiên trong một khoảng xác định, chẳng hạn ±5%, và mô hình DDF-DEA được chạy lặp lại 200 lần. Từ 200 giá trị hiệu quả \(\beta\) thu được, kết quả được tổng hợp bằng phân vị 95% (P95), nhằm phản ánh mức hiệu quả ở phía bất lợi của phân phối mà không lấy giá trị cực đoan nhất.
